# 피봇 검토 — 뽑을 게 없어졌을 때

> 선물과 숙소가 확정되면서 뽑기의 대상이 사라졌습니다.
> 무엇이 죽고 무엇이 사는지 정리하고, 이벤트 형식을 다시 고릅니다.

---

## 1. 먼저 짚을 것 — 봉인은 안 죽었습니다

**"정해졌다"는 건 다영님이 정했다는 뜻이지, 영은이가 안다는 뜻이 아닙니다.**

이 기획의 척추는 원래 이거였습니다.

```
뽑기(결과 미확정) → 봉인 → 13일 → 개봉
```

여기서 죽은 건 **첫 칸 하나**뿐입니다. 봉인할 대상은 그대로 있고, 영은이는 여전히 모르고,
13일도 그대로 흐르고, 개봉의 순간도 그대로입니다.

| 요소 | 상태 |
|---|---|
| 야바위 뽑기 시퀀스 · 확률표 · 도감 · 몬티홀 펀치라인 | ❌ 대상 소멸 |
| 13일 조각 해제 (타일 · 블러 · 채도) | ✅ 무관 |
| 데일리 키 (스크래치 · 퀴즈 · 편지) | ✅ 무관 |
| 밀랍 온도 · 보장 게이지 · 별자리 · 알림 | ✅ 무관 |
| 개봉 세리머니 + 빛기둥 | ✅ 무관 |
| 해시 검증 · 봉인 증서 | ✅ 무관 — "언제 정해졌나"는 여전히 증명 가능 |
| Wrapped · 여정 모드 · 타임캡슐 | ✅ 무관 |

**22개 화면 중 뽑기는 8개(S02~S09)입니다.** 나머지 14개는 손댈 필요가 없습니다.
즉 이건 기획을 뒤엎는 문제가 아니라, **비어버린 한 칸을 무엇으로 채울지**의 문제입니다.

---

## 2. 이벤트 형식 지도

리서치해 보니 이 장르는 대략 일곱 갈래로 나뉩니다.

| 형식 | 구조 | 우리와의 거리 |
|---|---|---|
| **타임캡슐형** | 봉인된 편지가 정해진 날 열림 | **현재 우리 위치.** 단 경쟁 앱 다수 (§3) |
| **어드벤트형** | 매일 하나씩 열기 | 이미 13일 대기로 흡수함 |
| **보물찾기형** | 선물을 숨기고 찾게 함. 개수를 안 알려주는 게 포인트 | 호텔 이동 구조와 잘 안 맞음 |
| **미션 · 단서형 (방탈출)** | 단서를 풀어야 다음 단계가 열림 | **가장 유망.** §4-C |
| **분할 증정형** | N개를 하나씩 나눠 줌 (1주년에 11가지 선물 등) | 선물이 하나면 성립 안 함 |
| **영상 편지형** | 사진·영상을 편집한 추억 영상 | Wrapped가 이미 같은 자리를 차지 |
| **서프라이즈 파티형** | 사람 모아 놓고 놀래킴 | 1박 2일 여행과 상충 |

방탈출 업계는 실제로 **프로포즈 테마를 상품으로 운영**합니다. 기념일 관련 문제를 추가하거나
테마 내부를 이벤트용으로 꾸며주는 식이고, 개인이 직접 하는 홈 이벤트도
"가는 길에 미션 3개, 도착 30분 전에 영상" 같은 **이동 중 단계 진행** 패턴이 정착돼 있습니다.

## 3. 경고 — 타임캡슐만 남기면 무료 앱과 같아집니다

이게 이번 리서치에서 가장 중요한 발견입니다.

**"봉인된 편지가 정해진 날 열린다"는 이미 앱이 여럿 있습니다.**
Dear Me(미래의 나에게), 캡슐투미, 리마인, 타임버블, SKT 100년의 편지 —
심지어 Dear Me는 **6자리 코드로 상대에게 봉인 편지를 보내는 기능**까지 있습니다.

그러니 뽑기를 들어낸 자리를 그냥 비워두면, 이 앱은 무료 앱으로 대체 가능한 것이 됩니다.

우리만 가진 건 두 가지입니다.

1. **13일간 서서히 드러나는 카드** — 어느 타임캡슐 앱에도 없습니다
2. **개봉 세리머니** — 60초 정적, 빛기둥, 밀랍 파괴

**이 둘은 무슨 일이 있어도 지켜야 합니다.** 피봇의 기준선은 여기입니다.

## 4. 선택지

### A. 뽑기만 들어낸다 (축소)

다영님이 주최자 모드에서 결과를 입력하고, 영은이는 D-14에 **봉인 의식만** 합니다.
1.5초 홀드 → 밀랍. 그게 전부입니다.

- **비용 최저.** `draw-sequence.md` 전체가 빠지므로 개발량이 크게 줍니다
- **문제:** D-14에 영은이가 할 게 버튼 한 번뿐입니다. 세리머니라기엔 빈약하고,
  13일 대기의 출발점으로 무게가 안 실립니다

### B. 뽑기 대상을 바꾼다 (축 이동)

아직 안 정해진 걸 뽑게 합니다 — 개봉 시각, 개봉 순서, 당일 첫 활동 같은 것.

- **문제:** 무게가 안 맞습니다. 야바위 40초와 "개봉 시각 뽑기"는 어울리지 않아요.
  연출의 크기가 대상의 크기를 넘으면 공허해집니다

### C. 하루 종일 단계 개봉 (방탈출형) ★ 추천

아침에 한 번에 여는 대신 **하루에 걸쳐 네 번 엽니다.**

```
D-day 09:19   1차   선물 공개.  그리고 한 줄 — "오늘 밤 어디로 가는지는 아직."
      이동 중  2차   폰에서. 단서 또는 미션 하나를 풀면 열림
      15:00   3차   목적지 확정 공개 (체크인 직전)
      21:00   4차   마지막 봉인 — 편지 / 타임캡슐
```

- 13일 대기와 개봉 세리머니를 **그대로 유지**하면서
- 원래 아침 10분으로 끝나던 이벤트가 **하루 종일 작동**합니다
- 여정 모드가 이미 폰 웹으로 설계돼 있어 2·3·4차가 자연스럽게 얹힙니다
- 방탈출 홈 이벤트의 "이동 중 미션" 패턴을 그대로 가져온 것이라 검증된 형식입니다
- **개발량은 오히려 줍니다.** 가장 큰 덩어리(뽑기 8화면)가 빠지고 여정 모드가 조금 커지는 정도

### D. 보물찾기 하이브리드

앱은 힌트만 주고 실물 선물은 집 안에 숨깁니다.
"선물 개수를 안 알려주고 찾게 하는" 재미가 있지만, 호텔로 이동하는 구조라
집 안 보물찾기는 그날의 동선과 겉돕니다. C의 2차 개봉에 부분적으로 섞는 정도가 적당합니다.

### E. 역할 반전

영은이도 다영님에게 뭔가를 봉인합니다. 상호성이 생기지만 **영은이가 이벤트의 존재를
미리 알아야 하므로 서프라이즈가 깨집니다.** 부적합.

## 5. 추천 — A + C

**뽑기는 들어내고, 그 자리에 하루 종일 단계 개봉을 넣습니다.**

억지로 뽑기를 살리려다(B) 무게가 안 맞는 대상에 40초 연출을 붙이는 것보다,
비워내고 다른 축을 키우는 쪽이 낫습니다.

### 새 구조

```
D-14      봉인 의식     다영이 입력 → 영은이 홀드로 봉인. 카드 4장이 동시에 잠김
D-13~D-1  13일 대기     그대로 유지
D-day     4단계 개봉    09:19 / 이동 중 / 15:00 / 21:00
D+1       타임캡슐      1년 뒤로
```

### 봉인 카드가 2장에서 4장으로

대기 화면에 카드가 네 장 놓입니다. 다만 **13일간 드러나는 건 1번(선물) 한 장뿐**이고,
나머지 세 장은 잠긴 채 실루엣으로만 보입니다.

이게 두 가지를 동시에 해결합니다.

- 타일 수치를 다시 잡을 필요가 없습니다 (54타일 · 상한 40장 그대로)
- **"아직 안 열린 게 세 개 더 있다"가 매일 눈에 보입니다.** 대기 화면이 오히려 풍성해집니다

### 봉인 의식은 이렇게 살립니다

뽑기가 없어도 D-14를 빈약하게 두면 안 됩니다. 홀드 한 번 대신 **네 번 봉인**하게 하세요.

```
카드 1  선물        → 1.5초 홀드
카드 2  단서        → 1.5초 홀드
카드 3  목적지      → 1.5초 홀드
카드 4  마지막 편지 → 2.5초 홀드   ← 마지막만 길게
```

네 번 반복되는 동작에 마지막만 길이가 다르면 그 자체로 리듬이 생깁니다.
야바위만큼은 아니어도 "의식"으로는 충분합니다.

## 6. 무엇을 잃는가 — 정직하게

피봇하면 아래는 버려집니다. 아까운 순서대로 적었습니다.

1. **몬티홀 펀치라인** — "애초에 꽝이 없었거든요. 그래도 그때 한참 고민했잖아요."
   이 기획에서 제일 좋은 문장이었는데 대상이 없으면 성립하지 않습니다
2. **확률 공개 패러디** — 33.34 / 33.33 / 33.33. 뽑을 게 없으니 확률도 없습니다
3. **야바위 셔플** — 스왑 타이밍 설계가 통째로
4. **탈락 카드 · 도감** — 도감은 4단계 봉인의 진행도 화면으로 형태를 바꿔 일부 살릴 수 있습니다

`draw-sequence.md`는 지우지 않고 **보류 상태로 남겨둡니다.** 나중에 뽑을 만한 대상이
다시 생기면(다음 기념일 등) 그대로 꺼내 쓸 수 있습니다.
