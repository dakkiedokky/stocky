> `docs/event-plan.md`의 기획을 실제로 재미있게 만드는 장치들입니다.
> 전부 구현할 필요는 없습니다. §10에 우선순위를 매겨두었습니다.

## 0. 설계 원칙

이 이벤트의 진짜 상품은 선물이 아니라 **13일간의 기다림**입니다.
선물은 하루면 끝나지만 기다림은 13일간 매일 작동합니다. 그래서 대부분의 설계 노력은
뽑기와 개봉 사이의 빈 구간에 들어갑니다.

기다림을 설계할 때 지켜야 할 세 가지:

1. **매일 화면이 달라 보여야 한다.** "어제랑 똑같네"가 한 번 나오면 그날로 끝입니다.
2. **참여는 보상하되, 불참은 벌하지 않는다.** 하루 걸렀다고 손해를 보면 그건 숙제입니다.
3. **D-day 직전에 70%쯤 알 것 같아야 한다.** 100%면 서프라이즈가 없고, 30%면 13일이 헛수고입니다.

## 1. 카드 조각 해제 — 3중 레이어

봉인된 카드 앞면을 세 겹으로 덮어두고, 각 레이어가 **서로 다른 속도로** 걷힙니다.
한 가지 방식만 쓰면 13일이 단조로워집니다.

| 레이어 | D-13 | D-1 | 걷히는 방식 |
|---|---|---|---|
| ① 타일 | 100% 덮임 | 26~74% 열림 | 하루 몇 장씩 사라짐 (참여도에 따라 변동) |
| ② 블러 | `blur(60px)` | `blur(6px)` | 매일 조금씩 초점이 잡힘 |
| ③ 채도 | 흑백 | 컬러 | **마지막 3일에만** 색이 돌아옴 |

블러가 심리적으로 가장 중요합니다. 타일만 벗기면 "가려진 부분"과 "보이는 부분"이
딱딱하게 나뉘지만, 블러는 **전체가 서서히 또렷해지는** 감각이라 훨씬 애가 탑니다.
채도를 마지막 3일에 몰아둔 것도 같은 이유입니다 — 마지막에 확 달라지는 구간이 필요합니다.

### 1.1 타일 수치 설계

카드 한 장을 **6 × 9 = 54 타일**로 나눕니다.

```
기본 지급    하루 2장 × 13일          = 26장 (48%)
퀴즈 보너스  정답 1개당 +1장 (최대 13) = 최대 39장 (72%)
공개 상한    40장 (74%)  ← 이 이상은 열리지 않음
잠금 타일    14장 (26%)  ← D-day 전에는 절대 안 열림
```

**잠금 타일이 핵심 장치입니다.** 제품 로고, 숙소 간판, 브랜드 마크처럼 정답이 확정되는
영역의 좌표를 카드별로 미리 지정해 두고, 이 타일들은 어떤 경우에도 D-day 전에 열리지
않습니다. 나머지 40장은 자유롭게 열려도 안전합니다.

이 구조 덕분에 "거의 다 벗겨졌는데 아직도 확신이 안 서는" 상태를 의도적으로 만들 수 있습니다.
참여도에 따라 48%(무성의)에서 74%(매일 참여)까지 갈리므로 매일 켤 동기도 생깁니다.

### 1.2 열리는 순서

무작위로 열면 안 됩니다. 가장자리와 배경부터 열고 중앙으로 좁혀 들어옵니다.
콘텐츠 제작 시 카드마다 타일 우선순위 맵을 하나씩 만듭니다.

```
우선순위 1  배경 · 하늘 · 바닥       ← 정보량 거의 없음
우선순위 2  주변 사물 · 질감
우선순위 3  피사체 외곽선
잠금        로고 · 간판 · 결정적 형태  ← D-day 전용
```

### 1.3 보장 게이지 — 천장의 재해석

가챠 게임에는 천장이 있습니다. 아무리 운이 나빠도 N번 안에는 나온다는 안전장치죠.
리서치에 따르면 천장의 진짜 기능은 확률 보정이 아니라 **"눈에 보이는 목표"를 주는 것**입니다.
카운터가 차오르는 게 보이면 운이 나쁜 구간도 버틸 이유가 생깁니다.

우리는 이걸 **참여도 게이지**로 바꿔 씁니다.

```
타일 수집   ████████████░░░░░░  28 / 40
            ↑ 40장을 다 모으면 개봉 시 선물 하나가 추가로 확정됩니다
```

봉인 대기 화면 하단에 상시 노출합니다. 별자리(5.2)는 밤에 켜야만 보이는 숨은 보상이지만,
이 게이지는 **매일 눈에 들어오는 명시적 목표**입니다. 둘의 역할이 다릅니다.

40장을 채우면 실제로 뭘 하나 더 주세요. 게이지를 채웠는데 아무 일도 안 일어나면
그다음부터 이 앱의 모든 약속이 가벼워집니다.

## 2. 데일리 키 — 하루 한 번의 인터랙션

타일이 자동으로 벗겨지기만 하면 영은이는 관객일 뿐입니다. 하루에 하나, 작은 행동을 넣습니다.
앱을 켜면 오늘의 키가 셋 중 하나로 정해져 있습니다.

### 🔑 A. 스크래치 (등장 빈도 5/13)

은박으로 덮인 사각형을 마우스로 긁어냅니다. 럭키드로우 포토카드의 그 감각 그대로.
60% 이상 긁으면 자동으로 나머지가 벗겨지고, 아래에서 오늘의 타일이 나옵니다.

긁는 소리를 꼭 넣으세요. 이 인터랙션은 소리가 절반입니다.

### 🔑 B. 퀴즈 (등장 빈도 5/13)

둘의 기억에서 낸 4지선다 한 문제.

> 우리가 처음 만난 날, 내가 입고 있던 옷 색은?
> 작년 생일에 갔던 카페 이름은?
> 내가 제일 자주 하는 말버릇은?

**맞히면 보너스 타일 1장, 틀려도 그냥 넘어갑니다.** 틀렸을 때 정답과 함께 짧은 코멘트가
뜨는 게 오히려 재미 포인트입니다. 오답을 벌로 만들지 마세요.

### 🔑 C. 봉투 (등장 빈도 3/13)

타일도 퀴즈도 없이, 다영님이 미리 써둔 짧은 편지 한 통만 나옵니다.
힌트가 아니라 그냥 편지입니다.

솔직히 말하면 **영은이가 가장 좋아할 부분은 아마 이겁니다.** 13개 중 3개만 배정한 건
희소성 때문입니다. 매일 나오면 편지가 아니라 알림이 됩니다.

### 2.1 밀린 날 처리

하루를 건너뛰면 다음 실행 시 밀린 만큼 **순차 재생**됩니다. 3일 치가 밀렸으면
3일 치가 차례로 열립니다. 스크래치도 3번 합니다.

한꺼번에 뭉쳐서 "3장 획득!"으로 처리하면 안 됩니다. 하나씩 재생돼야 손해 본 느낌이 없습니다.

## 3. 뽑기 세리머니

### 3.1 슬롯 구성

**숙박과 당일 미션은 뽑기에서 뺐다가, 호텔을 다시 넣었습니다.** 슬롯당 정확히 3장입니다 —
3장이어야 야바위가 성립하기 때문입니다.

| 슬롯 | 카드 | 내용 |
|---|---|---|
| **1 — 선물** | 3 | 갤럭시 워치 9 / 갤럭시 탭 / 이북 |
| **2 — 호텔** | 3 | 더미 A / B / C — [`hotels.md`](hotels.md)에서 확정 |

조합 3 × 3 = **9가지**. 조커는 없앴습니다. "전부 다" 같은 보너스는 보장 게이지 보상(§1.3)이
같은 역할을 하니까요.

슬롯은 데이터입니다. 식당을 3장짜리 세 번째 슬롯으로 넣고 싶으면 항목만 추가하면 됩니다.

### 3.2 뽑기는 한 번에 끝나지 않습니다

세 개 중 하나로 운명이 갈리는 순간이라 **흔들고, 되묻고, 멈칫하는** 시퀀스를 넣었습니다.

```
야바위 셔플 → 선택 → 탈락 카드 → "바꾸시겠습니까?" → "정말입니까?"
            → 뒤집히려다 멈춤 → (50%) 한 번 더 섞기 → 봉인
```

슬롯 하나당 40~55초입니다. 스왑 타이밍, 페이크 예산, 상태 머신, 결과 확정 시점까지
**전부 [`docs/draw-sequence.md`](draw-sequence.md)에 있습니다.** 여기서는 두 가지만 짚습니다.

**탈락 카드는 내용을 공개하지 않습니다.** 3장이 2장으로 좁혀지면 13일 긴장이 반토막 납니다.
`✕ 탈락`이라고만 적힌 VOID 면으로 뒤집히고, 진짜 내용은 개봉 때 밝혀집니다 —
"바꿨으면 이거였습니다."

**페이크는 2회까지입니다.** 세 번을 넘기면 긴장이 아니라 짜증이 되고,
생일에 짜증은 회복이 안 됩니다.


### 3.5 확률 공개 — 패러디

한국은 2024년부터 확률형 아이템의 확률 공개가 법으로 의무화돼 있습니다. 이걸 그대로 흉내 냅니다.

뽑기 화면 구석에 아주 작게 `확률 정보 ⓘ`. 누르면 진짜 확률표가 뜹니다.

```
  선물 슬롯
  ├ 갤럭시 워치 9 ······ 33.34%
  ├ 갤럭시 탭 ·········· 33.33%
  └ 이북 ··············· 33.33%

  호텔 슬롯
  ├ 더미 A ············· 33.34%
  ├ 더미 B ············· 33.33%
  └ 더미 C ············· 33.33%

  ※ 본 이벤트의 모든 결과는 당첨입니다.
  ※ 미획득 카드는 소멸하지 않으며 향후 기념일에 재출현할 수 있습니다.
  ※ 탈락 카드의 내용은 개봉 시 공개됩니다.
```

33.34 / 33.33 / 33.33으로 합을 정확히 100%에 맞추는 게 웃음 포인트입니다.
마지막 두 줄은 실제 게임의 고지문 어투를 그대로 가져온 것이고요.
게임 하는 사람이면 이 디테일에서 한 번 웃습니다.

### 3.6 도감

뽑히지 않은 카드는 사라지지 않고 **실루엣으로 도감에 남습니다.**

개봉 후 도감 화면을 열면 획득한 카드는 컬러, 탈락 카드는 이때 정체가 공개되고,
1차에서 아예 안 고른 카드는 회색 실루엣에 `???` 로 남습니다.
"이번에 안 나온 것들"이 눈에 보이면 다음 기념일이 자동으로 예고됩니다.
수집 게임이 도감을 먼저 보여주는 이유가 이겁니다 — 빈칸이 다음 플레이의 동기입니다.

## 4. 정직성 — 결과가 그날 정해졌음을 증명하기

뽑기 결과는 주최자만 압니다. 그런데 나중에 영은이가 이렇게 물을 수 있습니다.
**"이거 사실 그때 정한 거 맞아? 나중에 바꾼 거 아니야?"**

게임 업계에서 쓰는 provably fair 방식을 그대로 씁니다. 개발자 감성으로도 재미있는 부분입니다.

```
뽑기 시점  결과 JSON + 랜덤 솔트 → SHA-256 → 앞 12자리를 증서에 인쇄
개봉 시점  앱이 원본 JSON과 솔트를 공개
검증      영은이가 직접 해싱해서 증서의 값과 대조
```

증서의 해시는 13일 내내 냉장고에 붙어 있었고, 개봉 후 계산한 값이 그것과 같다면
결과는 그날 확정된 것입니다. 수학적으로 반박이 안 됩니다.

앱에 **검증 화면**을 하나 넣어서 버튼 한 번으로 대조할 수 있게 합니다.

### 4.1 봉인 증서 (실물)

뽑기 직후 앱이 A5 PDF 한 장을 생성합니다. 인쇄해서 접고, 봉투에 넣고, 밀랍 스티커로 봉합니다.

```
             봉  인  증  서

  봉인 일시   2026-09-05 20:14 KST
  봉인 번호   #A7F3-2C91-8E04
  개봉 예정   2026-09-19 09:19 KST
  봉인자      영은

  이 봉투 안에는 아무것도 들어 있지 않습니다.
  내용은 화면 안에 있습니다.
```

마지막 두 줄이 포인트입니다. 뜯어봐도 아무것도 없다는 걸 미리 알려주는 게
오히려 안 뜯게 만듭니다. 봉투는 13일간 냉장고에 붙어 있는 **물리적 카운트다운**입니다.

디지털 화면은 안 켜면 없는 것과 같지만, 냉장고에 붙은 봉투는 지나갈 때마다 눈에 들어옵니다.
이 조합이 기다림을 훨씬 두껍게 만듭니다.

## 5. 기다리는 맛 — 시각적 장치

### 5.1 밀랍 온도

카운트다운을 숫자로만 보여주지 않습니다. **봉인 밀랍의 색이 13일간 서서히 변합니다.**

```
D-13   #3A2340   차갑게 굳은 짙은 자주
D-7    #6B2438   식은 자주빛 붉음
D-3    #9E2B3A   제 색을 찾은 밀랍
D-1    #C4332F   달아오르기 시작
D-day  #E8452C   붉게 달아오름 + 미세한 발광
```

숫자를 안 읽어도 색만 보고 "이제 얼마 안 남았다"가 읽힙니다.
정보를 텍스트가 아닌 형태로 전달하는 게 항상 더 강합니다.

### 5.2 밤에 켜면 — 별자리

21시 이후에 앱을 켜면 배경이 밤하늘로 바뀌고, **지금까지 획득한 타일 수만큼 별이 떠 있습니다.**
40개를 다 모으면 별들이 선으로 이어지며 별자리 하나를 그립니다.

그 별자리의 모양이 사실 **목적지의 실루엣**입니다. 마지막 힌트이자, 매일 참여한 사람에게만
주어지는 보상입니다. 48%만 모은 사람은 이 별자리를 못 봅니다.

구현 난이도 대비 임팩트가 큰 편이라 여유가 되면 꼭 넣으시길 권합니다.

### 5.3 데스크톱 알림

매일 21:00에 Windows 토스트 알림. 앱은 트레이에 상주합니다.

> 🕯️ 오늘의 조각이 열렸어요 · D-6

알림을 클릭하면 앱이 전체화면으로 올라옵니다. 이게 없으면 앱을 켜는 걸 잊어버리고,
잊어버리면 13일 설계가 통째로 무의미해집니다. **우선순위가 생각보다 높습니다.**

## 6. 개봉 — 가챠 게임에서 가져온 것들

리서치에서 가장 쓸모 있었던 발견은 이겁니다.

> 보상 연구에 따르면 사람은 어떤 신호가 좋은 결과를 예고하는지 학습하고 나면,
> **도파민 반응의 상당 부분이 보상 자체가 아니라 그 예고 신호로 옮겨갑니다.**
> 가챠 연출에서 소리가 바뀌고, 색이 변하고, 애니메이션이 느려지는 이유가 이것입니다.
> 결과가 나타나기도 전에 "뭔가 대단한 게 온다"를 먼저 알려주는 것이죠.

즉 **절정은 공개가 아니라 공개 직전**입니다. 지금 설계는 여기가 비어 있었습니다.

### 6.1 개봉 직전 60초

09:18:00부터 화면의 모든 UI가 사라지고 밀랍만 남습니다.
09:18:50부터 마지막 10초는 숫자가 화면 전체를 채웁니다. 사운드는 심장박동 하나만.

### 6.2 등급 텔 — 빛기둥

밀랍이 깨지면 카드가 바로 뒤집히지 않습니다. **먼저 빛기둥이 올라옵니다.**
원신을 비롯한 가챠 게임이 아이템 이름보다 등급 색을 먼저 보여주는 그 구조입니다.

```
은색  ────  1.2초  ────  금색으로 폭발  ────  카드 회전
      ↑                   ↑
   평범한 등급          여기가 진짜 절정
```

우리 이벤트에는 나쁜 결과가 없습니다. 그래서 **등급은 실제 값어치가 아니라 순수한 연출 장치**로만
씁니다. 모든 카드가 결국 금색으로 갑니다. 색이 정보를 전달하는 게 아니라 긴장을 만드는 역할만 합니다.

### 6.3 페이크 연출 — 조심해서 쓸 것

빛기둥이 은색으로 멈칫하는 1.2초가 near-miss 효과입니다.
"어? 이게 다야?" 하는 순간이 있어야 그다음 폭발이 살아납니다.

한 단계 더 나간 버전도 가능합니다. 카드가 뒤집히며 **먼저 엉뚱한 것이 보이고**,
1.5초 뒤 그 카드가 찢어지며 아래에서 진짜가 올라오는 방식입니다.

**다만 이건 위험합니다.** 생일에 진짜로 실망시키면 그 1.5초가 하루를 망칩니다. 규칙 두 개를 지키세요.

- 가짜 카드는 **명백히 장난이어야 합니다.** "편의점 상품권 5,000원" 같은 건 안 됩니다.
  "당첨: 다영이의 사랑 1kg", "당첨: 설거지 면제권 1회" 처럼 웃음이 먼저 나오는 것으로
- **1.5초를 넘기지 마세요.** 길어지면 장난이 아니라 상처가 됩니다

자신이 없으면 6.2의 빛기둥만 넣고 이건 건너뛰어도 됩니다. 빛기둥만으로도 충분히 작동합니다.

### 6.4 개봉 순서

```
1  빛기둥          은색 → 금색. 여기가 절정
2  선물 카드       제품 이미지 + 한 줄
3  식당 카드       오늘 저녁이 정해지는 순간
4  목적지          호텔 풀스크린 사진 — 뽑기가 아니라 확정이지만 공개는 함께
5  검증 화면       해시 대조. "그날 정해진 게 맞다"
6  도감            안 나온 카드들이 실루엣으로
7  Wrapped        
8  초대장          QR로 폰에 인계
```

선물 → 식당 → 목적지 순서인 이유는 **정보의 무게가 커지는 순서**여서입니다.
목적지 사진이 화면을 가득 채우는 게 마지막이어야 합니다.

### 6.5 리플레이는 반드시

게임에는 연출 스킵이 있지만 우리는 반대입니다. **개봉 연출은 스킵할 수 없고, 대신 무한히 다시 볼 수 있어야 합니다.**

개봉 후 홈 화면에 `그날 다시 보기` 버튼을 상설로 둡니다. 그날 아침의 60초 정적부터
빛기둥까지 통째로 재생됩니다. 1년 뒤 타임캡슐이 열릴 때 이 버튼이 있으면 훨씬 좋습니다.

### 6.6 우리 Wrapped

스포티파이 Wrapped는 2025년에만 6억 2천만 회 공유되며 하나의 문화 현상이 됐습니다.
**포맷이 이미 익숙하다는 게 강점입니다.** 익숙한 포맷에 우리 데이터가 들어가면
설명 없이도 바로 읽힙니다.

목적지 공개 직후, 여정 화면으로 넘어가기 전에 세로 스크롤 카드로 재생합니다.
각 장면은 풀스크린, 한 장에 숫자 하나.

```
올해 함께 간 곳          14 군데      ← 지도에 점이 하나씩 찍힘
주고받은 메시지          23,481 통
같이 본 영화             9 편
영은이가 올해 가장 많이 한 말   "배고파"
찍은 사진                2,207 장
그리고 오늘                            ← 목적지로 연결
```

데이터는 API 연동 없이 다영님이 미리 수동 입력합니다. 카카오톡 대화 내보내기로
메시지 수 정도는 쉽게 셀 수 있고, 나머지는 대충이어도 아무 상관 없습니다.
**정확도가 아니라 "세어봤다"는 사실이 감동 포인트입니다.**

### 6.7 QR로 폰에 인계

집을 나서면 노트북은 두고 갑니다. 초대장 화면에 QR 코드를 띄워 폰으로 넘깁니다.

QR은 정적 호스팅된 웹 페이지를 가리킵니다. 오프라인 생성 라이브러리를 쓰므로
QR 자체는 인터넷 없이 만들어지고, 링크를 여는 시점에만 네트워크가 필요합니다.

## 7. 여정 모드 — 이틀 내내 작동하기

개봉이 아침 10분짜리 이벤트로 끝나면 아깝습니다. 폰에서 열리는 웹 페이지가
1박 2일 동안 계속 살아 있습니다.

- **현재 시각 기준으로 다음 일정이 자동 하이라이트.** 스크롤할 필요 없이 지금 뭘 할 차례인지 보임
- **각 일정마다 사진 슬롯.** 그 자리에서 찍어 올리면 여행이 끝날 때 앨범이 저절로 완성
- **미션 카드 체크박스.** 뽑은 미션의 진행 상황
- **일정마다 잠긴 한 줄.** 해당 시각이 지나야 열리는 다영님의 코멘트

마지막 항목이 좋습니다. 이틀 내내 작은 개봉이 계속 이어집니다.

## 8. 애프터 — 이벤트를 끝내지 않기

9월 20일 밤, 집에 돌아와 앱을 켜면 화면이 하나 더 남아 있습니다.

> **1년 뒤 오늘 열리는 편지를 써두세요.**

둘이 각자 편지를 쓰고 봉인합니다. 개봉 예정 시각은 **2027-09-19 09:19**.
같은 앱이 그날 다시 열립니다.

이걸 넣으면 이 프로젝트가 일회성 이벤트가 아니라 **매년 돌아오는 의식**이 됩니다.
코드는 이미 다 있으니 화면 하나만 더 만들면 됩니다. 투자 대비 회수가 가장 큰 기능입니다.

## 9. 게임화 점검

요청하신 대로 지금 설계가 충분히 게임스러운지 냉정하게 봤습니다. **결론은 "기다림은 훌륭한데 뽑기가 약하다"였고**, 그래서 §3과 §6을 크게 고쳤습니다.

| 게임의 장치 | 원래 설계 | 지금 |
|---|---|---|
| 예고 신호 (anticipation cue) | ✗ 없음. 카드가 그냥 뒤집힘 | ✓ 빛기둥 은색 → 금색 (§6.2) |
| near-miss | ✗ | ✓ 은색에서 1.2초 멈칫 (§6.2), 선택적 페이크 카드 (§6.3) |
| 천장 · 진행도 | △ 별자리만. 밤에만 보임 | ✓ 보장 게이지 상시 노출 (§1.3) |
| 확률 공개 | ✗ | ✓ 패러디 확률표 (§3.5) |
| 선택의 순간 | △ 클릭 1회 | ✓ 야바위 → 선택 → 스위치 → 확인 (`draw-sequence.md`) |
| 도감 · 수집 | ✗ | ✓ 미획득 카드 실루엣 (§3.6) |
| 출석 보상 | ✓ 데일리 키 | ✓ 유지 |
| 리플레이 | ✗ | ✓ 그날 다시 보기 (§6.5) |
| 변동 보상 (variable ratio) | — | **의도적으로 안 넣음** ↓ |

### 일부러 안 가져온 것

가챠 게임의 핵심 엔진은 **변동비율 강화**입니다. 언제 나올지 모르는 보상을 계속 시도하게 만드는
구조죠. 이건 리서치에서 도박 기제와 같은 계열로 분석되는 부분이고, 반복 과금을 끌어내려고
설계된 것입니다.

우리 이벤트는 **뽑기가 단 한 번**입니다. 반복이 없으니 이 엔진은 애초에 돌아가지 않고,
돌릴 이유도 없습니다. 가져온 것은 **연출 문법**(예고 신호, near-miss, 등급 텔, 도감)이지
**수익화 구조**가 아닙니다. 이 구분을 흐리면 생일 선물이 아니라 소셜 카지노가 됩니다.

같은 이유로 "다시 뽑기" 버튼은 넣지 않습니다. 한 번뿐이라 무겁습니다.

## 10. 우선순위

전부 만들 필요 없습니다. 위에서부터 자르세요.

### 필수 — 이게 없으면 이벤트가 성립 안 함

1. 주최자 모드 (결과 확인 → 예약)
2. 야바위 뽑기 시퀀스 + 봉인 (`draw-sequence.md`)
3. 카운트다운 + 개봉 연출 + **빛기둥**
4. 타일 해제 (3중 레이어 중 타일 + 블러)
5. 데스크톱 알림

3번의 빛기둥이 필수로 올라온 게 이번 변경의 핵심입니다. 개봉 연출에서 이것만 빼면
나머지를 다 만들어도 밋밋합니다.

### 강력 추천 — 재미의 대부분이 여기서 나옴

6. 데일리 키 3종 (스크래치 · 퀴즈 · 봉투)
7. 보장 게이지
8. 확률 공개 패러디
9. 밀랍 온도
10. 봉인 증서 PDF + 해시 검증
11. 도감
12. QR 인계 + 여정 모드

### 여유 되면

13. 우리 Wrapped
14. 리플레이
15. 별자리
16. 페이크 카드 (§6.3 — 자신 없으면 넣지 마세요)
17. 타임캡슐
18. 채도 레이어

**13번(Wrapped)은 만드는 건 쉬운데 데이터 수집이 오래 걸립니다.** 만들기로 했다면
지금부터 세어두세요. 코드보다 이쪽이 리드타임이 깁니다.


## 11. 실물 쪽 — 2026 굿즈 트렌드 접목

리서치해 보니 올해 굿즈 시장 흐름 중 이 이벤트에 바로 쓸 수 있는 게 몇 개 있었습니다.

**감정 안정 굿즈** — 불확실성이 커지면서 스트레스볼이나 봉제인형처럼 감정적 안정을 주는
굿즈 수요가 빠르게 늘고 있습니다. 뽑기 결과와 무관하게 개봉 시 함께 주는 작은 인형을
하나 준비해 두면 좋습니다. 앱에 캐릭터를 만들었다면 그 캐릭터로 만들면 더 좋고요.

**세트형 야외 굿즈** — Z세대 야외활동 참여율이 13.5% 증가하면서 피크닉 키트처럼
묶음 구성이 트렌드입니다. 글램핑이 뽑히면 담요 · 텀블러 · 블루투스 스피커를 한 박스로 묶어
"글램핑 키트"로 만드세요. 낱개로 주는 것보다 개봉의 밀도가 훨씬 높습니다.

**블라인드 박스** — 열기 전까지 모른다는 구조가 완구 산업의 핵심 사업 모델로 자리 잡았습니다.
실물 선물을 그냥 쇼핑백에 담지 말고 무지 박스에 넣으세요. 화면에서 한 번, 실물에서 또 한 번,
개봉의 순간이 두 번 생깁니다.

**로컬 굿즈** — 경험 중심 소비가 확산되며 지역 스토리를 담은 굿즈가 주목받고 있습니다.
미션 카드의 "그 동네 로컬 굿즈 교환하기"가 여기에 해당합니다. 여행의 기념품이
계획된 선물이 아니라 그날 우연히 고른 것이 되는 편이 오래 남습니다.

**어드벤트 캘린더** — 매일 하나씩 열어보는 재미로 국내 인지도가 빠르게 오르며,
DIY 제품과 주문제작 업체가 계속 늘고 있습니다. §1~2의 13일 구조가 정확히 이 포맷입니다.
여유가 되면 실물 어드벤트 캘린더를 같이 만들어 디지털 타일과 짝을 맞추는 것도 가능합니다.
냉장고의 봉투와 같은 역할이지만 훨씬 화려합니다.
